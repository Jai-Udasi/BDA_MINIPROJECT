The Operational Bottlenecks

  • Operational Persistence: MongoDB NoSQL operational store with SQLite local fallback.

5. Module 5: PCY Market Basket & Spatial Clustering

Advanced data mining algorithms for associative purchasing and physical delivery staging:

Park-Chen-Yu (PCY) Algorithm

  • Memory Bottleneck in Apriori: Classic Apriori creates $O(|L_1|^2)$ candidate pair counters in Pass 2.
  • PCY Two-Pass Hash Bitmap:
    • Pass 1: Hashes item pairs into integer bucket array $H$ of size $B$ using MD5.
    • Bitmap Conversion: Compresses $H$ to a 1-bit bitmap ($32\times$ memory reduction).
    • Pass 2 Pruning: Only counts pairs where $i, j \in L_1 \land \text{bitmap}[h(\{i, j\})] == 1$.
  • Discovered Rule: Chicken Biryani ⇒ Gulab Jamun (Support: 13.9%, Lift: 3.41).

Spatial Delivery-Hub Clustering

  • Curved Earth Geometry: Planar Euclidean distance fails across urban zones. Implemented the spherical Haversine Great-Circle formula ($R = 6371.0\text{ km}$).
  • Multi-K Hyperparameter Search: Evaluated $k \in [3, 8]$ using Inertia (WCSS) and Silhouette scores.
  • Optimal Centroids: Discovered optimal $k = 6$ staging hubs (Silhouette = 0.841) matching Mumbai clusters (Chembur, Kurla, Ghatkopar, Sion, Powai, Wadala).

7. Module 6: Bipartite Graph Link Analysis

Structural centrality analysis on the Customer-Restaurant interaction network in src/mining/link_analysis_recommender.py:

PageRank Centrality

Models random walk with teleportation across bipartite customer-restaurant edges:

PR_{t+1}(p) = (1 - d)/N + d * Σ (PR_t(q) / Out(q))

  • Damping Factor: $d = 0.85$ over power iteration.
  • Conservation: Total probability across all nodes strictly sums to 1.0.
  • Top Authority: Identifies anchor restaurants that capture consistent structural pull.

Kleinberg's HITS Algorithm

Mutually reinforcing Hubs and Authorities on customer-restaurant adjacency matrix $A$:

a = A^T * h,    h = A * a   (with L2 normalization)

  • Hub Scores ($h$): Influential customers who order across diverse high-volume restaurants.
  • Authority Scores ($a$): Premier culinary destinations attracting orders from prominent hubs.

12. Honest Technical Limitations & Future Work

Clear demarcation of academic simulation boundaries versus production deployments:

Current Academic Boundaries

  • Simulated Stream Transport: Ingestion emulates Kafka topic semantics in-memory; no distributed multi-broker Kafka cluster was deployed.
  • Synthetic Menu Items: Market basket itemsets were simulated deterministically to preserve the historical 14-column orders table.
  • Single-Node Spark: PySpark runs in local[*] multi-core mode rather than a physical multi-node Hadoop YARN cluster.
  • Offline Fallback: Persistent state runs on embedded SQLite when a live MongoDB Atlas/local daemon is absent.

Future Industrial Enhancements

  • Distributed Kafka & Flink: Connecting to real multi-broker Apache Kafka with Apache Flink stateful CEP.
  • Distributed GraphX / GraphFrames: Scaling PageRank and HITS to billions of customer-restaurant edges using Spark GraphX.
  • Deep Learning Recommenders: Neural Collaborative Filtering (NCF) and Two-Tower embeddings.
